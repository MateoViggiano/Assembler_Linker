mov format=> mov dest source
movb moves 1 byte
movw moves 2 bytes
movl moves 4 bytes
movq moves 8 bytes

derreferencing:
mov [dest] source	stores source into the address 'dest'
mov dest [source]	stores the value in the address 'source' into dest

addressing syntax:
[B+I*S+A]
B: Base Register  I=Index Register  S=Scaling factor  A=Address

rip = r15 : Instruction pointer
rsp = r14 : Stack pointer
rbp = r13 : Frame pointer
r10 : Return register
